# Selenium Hybrid Automation Framework 🚀

This is a **Hybrid Test Automation Framework** built using **Selenium WebDriver with Java, TestNG, and Maven**.  
It follows **Page Object Model (POM)** and supports **Data-Driven Testing, Parallel Execution, and Extent Reports**.

---

## 📌 Features
- ✅ Selenium WebDriver with Java
- ✅ Page Object Model (POM) Design
- ✅ TestNG-based execution & grouping
- ✅ Data-driven testing with Excel/Properties
- ✅ Logging with Log4j2
- ✅ Reporting with ExtentReports
- ✅ Retry mechanism for flaky tests
- ✅ Parallel execution with TestNG
- ✅ Multi-environment support (Dev, QA, Staging)
- 🚀 Exploring Jenkins CI/CD & Docker-based execution

---

## 🛠 Tech Stack
- **Language:** Java 17  
- **Framework:** Selenium WebDriver, TestNG  
- **Build Tool:** Maven  
- **Logging:** Log4j2  
- **Reporting:** Extent Reports  
- **Version Control:** GitHub  
- **CI/CD (Exploring):** Jenkins
